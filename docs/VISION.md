# Vision

## Problem

Developers often know what they want to change, but they still have to:

- Find the correct files
- Understand the code structure
- Write the code
- Run terminal commands
- Test the result

## Solution

A coding agent that takes a plain English prompt and does the work:

> "I want to add the checkout page after once the customer place order."

The agent should:

1. Understand the request.
2. Locate relevant files.
3. Edit the code.
4. Run commands if needed.
5. Ask for permission before dangerous actions.
6. Show what changed.

## Target Users

- Solo developers
- Small teams
- People building web apps
- Developers who want to save time

## Unique Angle

Instead of competing with giant general coding agents, this project will focus on:

- Simple integration into existing apps
- Clear permission and safety controls
- Free and open-source usage
- Learning-friendly design

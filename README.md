# Prompt Coder

An AI coding agent that modifies application code from natural language prompts.

## Vision

I want to build a coding agent that can:

- Understand a natural language request like:
  > "Add a checkout page after the customer places an order."
- Find the right files in the project.
- Modify the code automatically.
- Run terminal commands when needed.
- Let the developer review and approve important actions.
